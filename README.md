# Credit History Analyzer Bot

Telegram-бот на Python для анализа кредитной истории граждан Беларуси.

## Что делает

- Принимает PDF-файл с кредитной историей из Кредитного регистра
- Парсит данные через `pdfplumber`
- Определяет кредитный рейтинг (класс A–F)
- Находит стоп-факторы (просрочки, МФО, исполнительные листы)
- Считает текущую нагрузку по кредитам
- Подбирает банки, готовые рассмотреть заявку
- Рассчитывает платёж по кредиту и платёжную нагрузку
- Помогает с рефинансированием

## Технологии

- **Python 3.10+**
- **aiogram 3** — Telegram Bot API
- **pdfplumber** — парсинг PDF

## Как работает

1. Пользователь проходит анкету (10 вопросов)
2. Загружает PDF с кредитной историей
3. Бот анализирует документ, считает нагрузку, подбирает банки
4. Пользователь выбирает банк → получает расчёт платежа
